# Документация проекта Vostok

Кооперативная локализация подвижной сенсорной сети в трёхмерном пространстве. Краткое описание — в корневом `README.md` репозитория; здесь — полный комплект проектной документации.

## Оглавление

1. [Постановка задачи](01_postanovka_zadachi.md) — предметная область, организационный контекст практики, требования и критерии проверки решения.
2. [Концептуальное описание решения](02_concept.md) — модель мира, топология измерений, двухступенчатый алгоритм (градиентный спуск + EKF), фиксация системы отсчёта, метрики качества.
3. [Структура проекта](03_structure.md) — дерево каталогов, поток данных между модулями, назначение каждого файла, таблица тестовых сценариев, сборка и запуск.
4. [История создания](04_history.md) — разработка по 4 неделям / 20 рабочим дням практики, с результатами каждого дня.
5. [Формальные алгоритмы модулей](05_algorithms.md) — плоский псевдокод всех функций `pkg/*.go` и `cmd/main.go`.
6. [Результаты тестов](06_test_results.md) — сводная таблица метрик по 10 регрессионным сценариям, интерпретация, графики.

## `legacy/` — исторические заметки

Черновые design-документы, зафиксировавшие мотивацию ключевых архитектурных решений на момент их принятия (сохранены как объяснение "почему", актуальное поведение системы — в разделах 1–6 выше):

- [`legacy/error_growth_model.md`](legacy/error_growth_model.md) — обоснование квадратичной модели роста навигационной ошибки.
- [`legacy/logic_refactor_plan.md`](legacy/logic_refactor_plan.md) — устранение трёх дефектов коррекции (байесовское взвешивание, откат неудачного шага, Кабш, персистентная ковариация EKF).
- [`legacy/dynamics_config_refactor.md`](legacy/dynamics_config_refactor.md) — вынос параметров временной динамики в TOML, консолидация тестовых сценариев.
- [`legacy/knn_topology_plan.md`](legacy/knn_topology_plan.md) — переход к асимметричной k-NN топологии измерений.

## `images/`

Графики сходимости и динамики метрик по каждому из 10 тестовых сценариев (см. [06_test_results.md](06_test_results.md)).
