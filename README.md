# Документация

Моделируется кооперативная локализация подвижной беспроводной сенсорной сети в 3D (cooperative network localization): группа объектов уточняет свои координаты по взаимным замерам дальности, компенсируя дрейф GPS.

Модель мира (pkg/environ):

- N узлов в кубе [sMin, sMax]³. Каждый узел хранит 4 координаты: RealCoord (истина), BelievedCoord (своё дрейфующее представление, GPS/ИНС), InitialCoord (якорь регуляризации), CurrentCoord (оценка алгоритмов).
- Первые anchorsCount узлов — анкеры с точными координатами, исключены из оптимизации.
- Дальномеры: матрица попарных расстояний = истинное расстояние + равномерный шум ±distErr.

Двухступенчатая оценка (pkg/algorithms):

1. Градиентный спуск — минимизация невязок между расчётными и измеренными дальностями (MDS/spring-модель, множитель 1 − d_meas/d_calc) + L2-регуляризация к InitialCoord с весом λ (не даёт каркасу «уплыть» — дальности инвариантны к сдвигу/повороту, GPS-привязка убирает эту неоднозначность).
2. EKF — итеративное уточнение: состояние = координаты подвижных узлов, измерения = дальности, Якобиан из единичных векторов направлений, стандартный цикл predict/update (P+=Q, K = PHᵀS⁻¹, X += KY).

Топология измерений — асимметричный k-NN: каждый подвижный узел «стреляет» дальномером по k ближайшим; CheckConnectivity проверяет достижимость анкера по направленному графу.

Временной процесс (тиковый цикл в main.go):

1. StepTrueMotion — случайное блуждание истинных координат (±motionSigma).
2. GrowUncertainty — квадратичный рост ошибки дрейфа (e = e₀ + k·t²) и размытие BelievedCoord — модель деградации инерциальной навигации.
3. Пересчёт дальностей по новым истинным позициям.
4. Переоптимизация GD+EKF с warm start (малое число итераций на тик).
5. Метрики: RawRMSE (дрейф без коррекции) vs FinalRMSE (после коррекции) → CompensationRatio — насколько сеть взаимными замерами компенсирует деградацию GPS.

Итог: симулируется процесс, где точная относительная геометрия (дальномеры) непрерывно исправляет накапливающуюся абсолютную ошибку позиционирования движущихся объектов.

## Модель мира

### ./pkg/environ/env.go

Функции:

- BuildMap генерирует случайную сеть узлов и расстояния между ними:

    1) для i от 0 до n−1:

        1) сгенерировать случайную точку P в кубе \[sMin, sMax\]³.
        2) сохранить P как истинную координату узла i.
        3) проверить условие i < anchorsCount:

            - true - узел i это якорь: все координаты = P, неопределённость = 0. i++.
            - false - узел i не якорь: сгенерировать шум D в диапазоне \[−gErr, gErr\]³, вычислить зашумлённую точку P' = P + D. i++.

    2) BuildDistanceMatrix;
    3) вернуть узлы, истинные координаты, матрицу расстояний.

- RecomputeDistances перестраивает матрицу расстояний на каждом тике

    1. извлечь RealCoord из каждого узла в список координат.
    2. вызвать buildDistanceMatrix с этим списком.
    3. вернуть результат.

- BuildDistanceMatrix создаёт матрицу расстояний между узлами

    1) для каждой пары точек (i, j), i ≠ j:

        1) вычислить истинное расстояние между координатами.
        2) добавить случайный шум в диапазоне \[−distErr, distErr\].
        3) проверить что расстояние положительно.

            - true - оставить как есть.
            - false - заменить малым положительным значением.

        4) записать результат симметрично в матрицу \[i\]\[j\] и \[j\]\[i\].

    1. вернуть матрицу.
