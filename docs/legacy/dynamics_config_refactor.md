# Заметка: вынос параметров динамики в TOML, объединение конфигов

> Историческая заметка (план, полностью реализован). Описывает переход от зашитых в код параметров временной динамики к конфигурируемой секции `[dynamics]` в TOML, а также объединение каталогов `config/simple/` и `config/anchors/` в единый плоский список `config/*.toml`. Итоговая структура конфигов — см. [../03_structure.md](../03_structure.md).

## Контекст и мотивация

Параметры временной динамики (число тиков, длительность тика, скорость роя, коэффициент роста ошибки, число итераций GD/EKF на тик) изначально были зашиты константами в `cmd/main.go` — сценарии нельзя было варьировать без пересборки бинарника. Конфигурационные файлы были искусственно разделены на `config/simple/` (без анкеров) и `config/anchors/` (с анкерами), хотя единственное содержательное отличие между ними — значение `anchors_count`. Поле `lambda` в некоторых старых TOML-файлах было «мёртвым» — в структуре `Config` такого поля не было, вес регуляризации к этому моменту уже вычислялся из дисперсий источников (см. [logic_refactor_plan.md](logic_refactor_plan.md)).

## Реализованные изменения

1. **`pkg/types/types.go`**: добавлена секция `Dynamics` в `Config` — `Ticks`, `Dt`, `SwarmSpeed`, `GrowthRate`, `GdItersPerTick`, `EkfItersPerTick`.
2. **`cmd/main.go`**: добавлены CLI-флаги с прежними зашитыми значениями как значениями по умолчанию (`-ticks`, `-dt`, `-swarm-speed`, `-growth-rate`, `-gd-tick-iter`, `-ekf-tick-iter`); при наличии `-config` эти шесть параметров читаются из `cfg.Dynamics`.
3. **Конфигурация**: каталоги `config/simple/` и `config/anchors/` объединены в плоский список `config/00_base.toml` … `config/09_anc_bad-gps.toml`; во все файлы добавлена секция `[dynamics]` с явными значениями (включая `anchors_count = 0` в бывших simple-сценариях), удалены упоминания мёртвого поля `lambda`.
4. **`testbench.py`**: упрощён до двух рабочих режимов (запуск одного конфига, пакетный запуск всех) — удалены второстепенные режимы (случайный конфиг, ручной ввод CLI-параметров, просмотр отчёта, текстовые фильтры, эмодзи и декоративное оформление вывода).
5. **`README.md`**: обновлены разделы «Запуск» (новые пути конфигов) и «Известные ограничения» (убраны пункты про хардкод динамики и мёртвую `lambda`, которые к этому моменту были устранены).

## Проверка

- `go build ./...` — успешная сборка.
- `go run ./cmd/main.go -config config/00_base.toml` — вывод содержит ожидаемое число тиков.
- Временный конфиг с изменёнными `ticks`/`swarm_speed` — подтверждено, что значения в выводе программы соответствуют конфигурации, а не зашитым константам.
- Запуск без `-config` (только CLI-флаги) — параметры динамики берутся из флагов.
- Пакетный прогон всех конфигов через `testbench.py` — `report.md` пополняется корректно, режимы работают без интерактивных подтверждений.
